# Spatial Pegasus 路演 HTML

这是 Spatial Pegasus「AI 世界编译器」的可编辑路演页面。

## 文件结构

- `index.html`：演示页面、样式与翻页逻辑，全部集中在一个文件中
- `assets/`：页面使用的 Logo、场景图与概念视觉素材

## 查看方式

可以直接双击 `index.html` 查看。为了获得更稳定的浏览器表现，也可以在当前目录运行：

```bash
python3 -m http.server 8766
```

然后访问：

```text
http://127.0.0.1:8766/
```

## 操作方式

- `←` / `→`：翻页
- `F`：进入或退出全屏
- `D`：打开实时 Demo
- 触控设备可以左右滑动翻页

## 编辑说明

- 页面文字、结构、CSS 样式和交互均位于 `index.html`
- 图片均使用 `assets/...` 相对路径，移动整个文件夹后仍能正常显示
- 实时 Demo 地址目前位于 `index.html` 底部脚本中的 `demoUrl`：

```js
const demoUrl = 'http://127.0.0.1:3200';
```

如需在另一台电脑运行 Demo，请将其修改为实际地址，或在本机启动对应的 Spatial Pegasus 产品项目。

## 素材说明

页面同时包含产品参考素材与为本次路演生成的概念视觉。现场演示结果请以实际运行系统为准。
